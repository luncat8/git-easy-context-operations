 Before applying, the extension now checks files directly beside the patch (not in subdirectories) against the binary diff’s new blob hash. A match is copied to the patch’s repository path, and the binary-only diff section is removed so the remaining patch can apply. Mailbox patches are handled too.

If there’s no unique hash match, the binary change is skipped and the report tells you to put the exact file beside the patch to have it included automatically. Text changes can still apply.
